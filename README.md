# Python Port Scanner
A simple and lightweight Port Scanner built using Python. This tool scans a target IP address or domain and checks which ports are open.

## Features
- Scan target IP address or hostname
- Detect open ports
- Fast and simple terminal-based tool
- Built using Python socket library
- Beginner-friendly project

## Technologies Used
- Python 3
- Socket Module
- Networking Basics

## How It Works
The scanner attempts to connect to ports on a target system. If the connection is successful, the port is marked as open.

## Installation
1. Clone the repository:
git clone https://github.com/abhijeet-soni248/Port_scanner.git
2. Navigate to the project folder:
cd Port_scanner
3. Run the program:
python port_scanner.py

## Usage
- Enter target IP address or domain
- Enter port range (example: 1 to 1024)
- Wait for the scan results

## Educational Purpose
This project is created for learning Python socket programming, networking, and cybersecurity basics.

## Disclaimer
Use this tool only on systems you own or have permission to scan. Unauthorized scanning may violate laws or policies.
